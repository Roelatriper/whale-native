# 进度与缺失功能

版本：0.1.0-preview.1；独立原生预览版。维护范围仅 Apple Silicon / macOS 13.5+。当前是 Swift AppKit 宿主 + Node 业务后台，不是完全 Swift 化或完整功能等价版。

## 已完成

- 原生非激活 pet / bubble 面板、透明命中、按下 / 长按 / 回弹、拖动缩放翻转与位置记忆。
- 默认蓝色鲸鱼娘、原版气泡轮廓、多尺寸 ICNS、内置按下 / 松开两段音效；同一个播放器管理时序，避免重叠。
- API 与 Codex 订阅模式二选一；5h / 周额度分开，任务消费按共享语义投影，不跨模式出现 API 金额。
- 首次点击额度，随后进入 / 刷新文案；点击气泡前进 / 关闭，保留原 48 条文案及 10:1 文字 / petpet 分支。
- 气泡进出 0.18 秒、内容交叉淡化 0.2 秒；减少动态效果为 0.1 秒；revision 拒绝旧回调覆盖新场景。
- 可设置点击空白关闭；基本独立桌面 / Codex 跟随；设置使用按需 WKWebView，关闭释放所有者。
- 复用 API 连接、规则预览 / 检测、账本、订阅详情、工坊与角色导入的业务页面和资源验证。
- 账户通知显示后确认、scope / 模式切换失效、启动不重播与子任务去重。
- 会话扫描 64 KiB 复用缓冲、逐行解析、明确顶层聊天正文提前跳过；保留 UTF-8 / 长任务 / 恢复语义。
- 独立源码目录，无旧桌面启动入口；默认文案已拆为 JSON。
- 自包含发行包：固定校验的官方 Node、运行代码 / 素材 / 许可内置，支持移动路径；外层 ad-hoc 签名。
- 测试、发行验证脚本、只读权限 macOS CI、来源与交接文档。

## 尚未完整实现 / 验收

| 项目 | 当前边界 |
| --- | --- |
| 复杂气泡编辑 | 基础保存序列可播放；多图、图文混排、完整 lib 编辑、动态渐变 / 背景 / 滚动未等价 |
| 自定义音效 | 仅内置按压 / 松开；自定义裁剪、事件组、任务音效尚未迁移 |
| 吸附与跟随 | 基本拖动 / clamp / 跟随；全套原吸附策略未迁移 |
| 自动化运维 | 没有开机启动、后台崩溃自动重启或自动更新 |
| 签名与平台 | 没有 Developer ID / 公证 / Intel / Universal / Windows / Linux |
| 跨机器行为 | 最低系统仅为构建目标，尚未在 macOS 13.5 实机验收 |
| 图像与输入 | APNG / WebP / EXIF、大图、触控板、移出边缘松开需更多人工测试 |
| 多窗口场景 | 多屏、Spaces、全屏、分辨率变化、睡眠唤醒需人工回归 |
| 真实业务 UI | 各服务商表单、真实文件导入 / 导出、并发账户通知仍需扩大覆盖 |
| 资源占用 | 合成预算和历史样本已有；发行包长期运行、反复设置 / 动图的总峰值未穷尽 |

已实现不等于所有输入、系统版本和服务商都已验收。实际验证只以 VALIDATION.md 为准。

## 后续优先级

1. 真实鼠标 / 触控板与焦点测试；在编辑器持续输入时触发完成通知，确认输入不中断。
2. 多屏 / Spaces / 休眠和 API / 订阅来回切换，不显示旧金额、误确认旧批次。
3. 真实服务商设置、角色 / 工坊导入导出；用非敏感数据验证持久化及取消。
4. 完成复杂气泡与自定义任务音效的常用路径。
5. 长时内存测量与开机启动 / 崩溃恢复；有开发者证书后做公证。
6. 后续阶段逐步迁移 Node 业务；不能将预估内存当实测。
